# Agent 交接模板

持续保存与中断恢复使用 [CHECKPOINT_TEMPLATE](CHECKPOINT_TEMPLATE.md)，每个角色维护自己的 `LATEST.md`；本模板用于阶段交付报告，不能代替代码副本和恢复检查点。

- 角色/实际 agent 标识：
- 任务与允许写入范围：
- 读取的 contract_version / demo 配置版本：
- 本次修改文件：
- 已完成的行为：
- 实际验证命令与结果：
- 未测试/未完成：
- 接口变更请求（现状、建议、原因、影响模块）：
- 风险或研究决定待定项：
- 提交给协调 agent 的下一步：
- 当前检查点路径、任务状态及代码取回位置：

保存到 `handoffs/<角色>/<日期>-<简短任务名>.md`。路径存在不代表交接完成；只有真实结果才能填写通过。
